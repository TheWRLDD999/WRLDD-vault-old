WRLDD VAULT — BATCH PUBLISHING UPDATE

Upload/replace index.html in the repository root, add wallpapers.json in the root, and create a wallpapers/ folder (the included README.txt can be used as its placeholder).

To publish a batch from the app: tap the logo five times, unlock the owner tools, select multiple images, and tap Prepare entire batch. The app downloads WRLDD-Vault-Wallpaper-Batch.zip. Extract it. Upload every image from its wallpapers/ folder into the repository's wallpapers/ folder, and replace the root wallpapers.json with the one from the ZIP. Commit once.

The local PIN only hides the owner interface on that device. It is not secure authentication. Never place GitHub credentials or tokens in public app code.
